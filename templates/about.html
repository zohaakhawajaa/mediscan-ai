About MediScan AI

A self-contained application for three clinical-data workflows: chest X-ray pneumonia screening, blood-test interpretation and PDF lab-report extraction — all running locally with no external services.

View model center See evaluated metrics

Chest X-ray screening

DenseNet121 binary classifier (PyTorch) that outputs a pneumonia probability for an uploaded image, with an optional Grad-CAM attention heatmap showing which regions most influenced the prediction. A model registry also supports locally trained checkpoints.

Blood-test interpretation

Compares entered laboratory values against configurable reference ranges and flags out-of-range results. It reports range compliance only and performs no diagnosis.

PDF report extraction

Extracts text from uploaded PDF lab reports, detects candidate measurements and routes them into the blood-test module. Scanned pages are reported honestly instead of being silently ignored.

Model & data provenance

Repositoryhuggingface.co/luanacarolina/pneumonia-chest-xray-classifier
ArchitectureDenseNet121 with a single-logit BCE head
Reported metricsAccuracy 84.1%, recall 99.7%, F1 88.7%, AUROC 96.6% — from the model card's Kermany test split (mean over 3 seeds); not re-validated clinically here. Specificity is modest (~0.62 for the ensemble), so false alarms on normal lungs are expected.
Training dataKermany et al. (2018) pediatric chest X-ray dataset, Guangzhou Women and Children's Medical Center, ages 1–5
LicenseCC BY 4.0 (weights and model card)
LimitationsValidated only on pediatric images from a single institution; over-predicts PNEUMONIA on low-resolution or heavily upscaled inputs (measured: specificity 0.0 on 28×28 upscaled data). Not validated for adults or clinical use.
Local fine-tunesOptional ResNet18 / EfficientNet-B0 checkpoints trained here on PneumoniaMNIST; they appear only after a real training run and carry their own measured metrics.

Privacy architecture

All processing is local: images and PDFs are handled by this server, report text is stored server-side with a 6-hour expiry rather than in the browser cookie, activity history stores metadata only, and no data is sent to third-party services.

Tech stack

Python, Flask, PyTorch / torchvision, PyMuPDF, Pillow, NumPy, pydicom (optional), pytest. Lightweight CSRF protection and CSP headers; single-process deployment (Flask dev server or Waitress).

Intended use

For research use only — not for diagnostic use. Trained on pediatric chest X-rays from a single institution; consult a qualified clinician.
