How a case flows

  • Ingest — image or PDF is validated, size-checked and kept on this server only.
  • Analyze — the selected model runs real inference; no values are invented if something fails.
  • Explain — Grad-CAM attention and quality warnings show where to be skeptical.
  • Measure — the evaluation lab scores models on the held-out PneumoniaMNIST split.
  • Review — results stay in session-scoped storage with automatic expiry.

Built to be trusted carefully

Every model card in this app separates reported metrics (from its original authors) from measured metrics (from local evaluation runs). A model that has not been trained here is shown as unavailable — never silently substituted.
